# M12 hardening and release

Architecture: A9.5, A9.6, A9.8, A9.9. Spec: S17 (operations), S19.18 (operations), S19.19.

**Goal:** sofar holds up at ten years of data, under faults and under attack, and can be installed, upgraded, backed up and restored by following its docs.

**Exit:** all suites are green and the release checklist below is complete.

---

### [ ] M12.1 performance (A9.8)
- Generate ten years of simulated data (hundreds of thousands of transactions) with `internal/sim`.
- Targets: the hero screen renders under 200 ms on the server; recompute of a changed old month with early cutoff finishes under 2 seconds; a rule backtest over full history runs under 10 seconds; the matcher assigns hundreds of open items under 1 second. Record these targets in `docs/config-defaults.md` (they are tunable expectations, not spec rules).
- Add indexes and tune queries. Benchmarks live in `*_bench_test.go` and run in CI on a schedule.

### [ ] M12.2 security review (A9.9)
- Auth bypass attempts, token scope enforcement, secret redaction in logs and every API response, CSRF and origin checks, rate limits, SQL injection, and XSS in descriptions and notes (bank strings are untrusted). Dependency scanning (`govulncheck`, `npm audit`) in CI.
- Run the `spec-auditor` agent over the security-relevant packages and fix every blocking finding.

### [ ] M12.3 chaos and fault injection (A9.5)
- Provider timeouts, partial account failures, token revocation, clock skew, Postgres restarts mid-job, and duplicate job delivery. Assert the invariants still hold and jobs are idempotent.

### [ ] M12.4 upgrade path (A9.6)
- Migration tests from every released schema version to head, with data preserved.
- An engine-version bump followed by `sofar recompute --all` yields explainable diffs only (a report of which months changed and why).
- Event log replay reproduces identical state.

### [ ] M12.5 demo (only if approved in A-009)
- `sofar demo` seeds one synthetic year from `internal/sim` into a throwaway database and serves it read-only, so the app can be shown without real data.

### [ ] M12.6 self-hosting docs
- `docs/self-hosting.md`: install, TLS (Caddy and nginx examples, including a reverse proxy on another machine with `SOFAR_BIND` and `TRUSTED_PROXIES`), backup and restore (Postgres dump plus encrypted export), upgrade, rollback, and recovering a lost authenticator. Update `README.md`.

### [ ] M12.7 release checklist
- All suites green, `/spec-check` reports no uncovered sections, every amendment decided, every ADR written, `docs/config-defaults.md` complete, `docs/progress.md` up to date, and the owner signs off.
