# M11 platform: API, webhooks, MCP, AI assistant, auth, backups

Spec: S17 (export, security), S19.5 (export, backup), S19.17, S19.18, S19.19. Architecture: A6, A8, A9.6, A9.9. ADR-0018.

**Goal:** scoped API tokens, webhooks, an MCP server, the opt-in AI assistant, full auth (passkeys, OIDC, sessions, panic lock), observability, and encrypted export and restore.

**Exit:** API contract tests pass, a restore-from-backup test passes (identical state hash), and the security tests pass. Refine the tasks at the start of the milestone.

---

### [ ] M11.1 API tokens and rate limits (S19.18)
- `api_tokens`: hashed at rest, scopes (read, write, per resource), an optional expiry, and last used. Creating one requires step-up auth.
- Per-token rate limits. The REST API is fully documented in `api/openapi.yaml`, versioned under `/api/v1`, with cursor pagination.
- A CLI (`sofar` subcommands or a small separate binary) using tokens.
- Tests: `TestS19_18_TokenScopesEnforced`, `TestS19_18_TokenHashedAtRest`, `TestA9_9_ScopeBypassAttempts`.

### [ ] M11.2 webhooks and streams (S19.18)
- HMAC-signed deliveries, retried with backoff, with a delivery log and replay, for the events listed in S19.18. Optional SSE (already added in M8) and MQTT.
- Webhook targets go through `internal/netguard` (public addresses only, unless the user explicitly allows private ones per endpoint).
- Tests: `TestS19_18_WebhookSignatureVerifies`, `TestS19_18_RetryAndReplay`.

### [ ] M11.3 MCP server (S19.17)
- Read-only tools sharing the REST service layer: spending queries, "why is my number $X", month comparisons, scenarios. Writes are gated behind explicit scoped tokens and confirmation.
- Tests: `TestS19_17_MCPReadOnlyByDefault`.

### [ ] M11.4 AI assistant (S19.17, opt-in)
- Off by default. The model is the user's own (a local endpoint or their own API key). It sees **aggregates only** unless the user widens the scope, with redaction of account numbers and names, per-tool permissions, and an **audit log of every prompt and tool call**.
- Q&A with citations, natural-language rule drafts (preview, never auto-applied), natural-language search, a monthly narrative, and merchant-only external suggestions (S18a: send only the normalized merchant string).
- Tests: `TestS19_17_OffByDefaultSendsNothing`, `TestS19_17_AggregatesOnlyUnlessWidened`, `TestS19_17_EveryCallAudited`, `TestS18a_ExternalSuggesterSendsOnlyMerchant`.

### [ ] M11.5 auth (S19.19)
- Passkeys first (go-webauthn), then TOTP and recovery codes (from M0), and optional OIDC (go-oidc) for self-hosted identity providers.
- Session list and revoke, trusted devices, login history with alerts, step-up auth for export, token creation and data deletion, and a **panic lock** (revokes every session immediately).
- An append-only audit log. Privacy mode was done in M8.
- **Encryption at rest** (S19.19): secrets are already AES-GCM encrypted. Add the optional full-database option as documented guidance (an encrypted volume) in `docs/self-hosting.md`, plus an opt-in application-level encryption of `raw_transactions.payload` and receipt files, keyed from `SOFAR_ENCRYPTION_KEY`.
- Tests: `TestS19_19_PanicLockRevokesAll`, `TestS19_19_StepUpRequiredForExport`, `TestS19_19_PasskeyRegisterAndLogin` (using a virtual authenticator in Playwright).

### [ ] M11.6 observability (S19.18)
- Metrics: sync age per account, review backlog, accuracy, job durations. Structured logs (redacted, M0.5), optional OpenTelemetry, and a **redacted diagnostics bundle** (no amounts, descriptions or credentials).
- Tests: `TestS19_18_DiagnosticsBundleRedacted`.

### [ ] M11.7 export, backup, restore (S17, S19.5)
- Export CSV, JSON and OFX. A **full backup** as an encrypted archive (ledger, events, rules, model snapshots, play data, config) with a passphrase-derived key (argon2id plus AES-GCM).
- Restore into an empty instance. Scheduled export to a local path, S3-compatible storage or WebDAV. A tax export by category and tag. A wipe-all option behind step-up auth and a confirmation (the one place deletion asks, S0 principle 3).
- Tests: `TestA9_6_RestoreYieldsIdenticalStateHash`, `TestS17_WipeAllRequiresConfirmAndStepUp`, `TestS19_5_ExportImportRoundTrip`.

### [ ] M11.8 migration importers (S19.5)
- Importers for other budgeting apps' exports, with a category-mapping wizard. Start with a generic CSV-plus-mapping path. Specific formats are added as the owner needs them.
