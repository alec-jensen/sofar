# ADR-0008: no scope cutoff

- status: accepted
- date: 2026-10-02
- refs: docs/spec.md S0, S19

## context
the owner wants the best possible version and relies on ai-assisted development for speed.

## decision
everything in the spec is in scope. work proceeds in dependency order via the milestone plan. no mvp or v1 cutoff.

## consequences
the test and simulation harness is essential. milestones keep the system working end to end at each step.
